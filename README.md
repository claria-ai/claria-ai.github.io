# claria-ai.github.io

Claria's website, served by GitHub Pages from the repo root.

The HTML pages are generated: edit `claria.yml` (parameters) or `templates/` (markup), then run `uv run build.py` (or `pip install jinja2 pyyaml && python3 build.py`) and commit the regenerated files. Don't edit the generated HTML directly — see `CLAUDE.md`.
